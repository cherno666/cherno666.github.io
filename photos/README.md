# 相册图片 / Photo assets

`gallery.html` 会自动读取这里的图片，按数字顺序展示：

- `1.jpg`、`2.jpg` … → 大图（灯箱打开时加载，最长边约 1600px）
- `thumbs/1.jpg`、`thumbs/2.jpg` … → 缩略图（网格列表用，约 450x600，加载很快）

## 想加新照片？
1. 把照片按原图命名规则接在后面，比如现有 36 张就加 `37.jpg`；
2. 同时生成对应的 `thumbs/37.jpg`；
3. 推送后刷新页面即可，无需改代码。

> 提示：本相册随 GitHub Pages 公开，任何人都可访问，请勿放置不宜公开的私密照片。
